## 为什么选择 Next.js？

Next.js 是目前最流行的 React 框架之一，它提供了：

- **文件系统路由**：页面即文件，直观易懂
- **SSG / SSR 支持**：静态生成和服务端渲染，SEO 友好
- **Turbopack**：极速的构建体验
- **Tailwind CSS 集成**：快速构建美观的 UI

## 博客的核心功能

这个博客虽然简洁，但具备了所有必要的功能：

1. **Markdown 文章**：所有文章用 Markdown 编写，方便管理
2. **标签系统**：为文章添加标签，便于分类
3. **响应式设计**：在手机和桌面端都有良好的阅读体验
4. **暗色模式**：跟随系统自动切换

## 写在最后

搭建博客只是一个开始，更重要的是持续输出有价值的内容。希望能通过这个平台，记录下自己的成长轨迹。
